## Add a new engagement

1. Create `special-projects/Bimbo/<slug>/` with a short `README.md`.
2. Keep client source under `source/`.
3. Put locked decisions in `LOCKS.md` before building factory tooling.
4. Link the folder from the hub [`README.md`](README.md).

## Do not

- Nest one git clone inside another under this hub
- Put Bimbo under `global-opportunities` or GL factories
- Use GL `{program}-t{n}-m{nn}` package naming until a commercial spine is chosen
